# Galeri tarayıcı kontrol notları

18 Ekim 2026 — yerel Vite sunucusu, gerçek dosya seçimi ve kullanıcı arayüzü üzerinden:

| İşlem | Gözlenen sonuç |
|---|---|
| Listeleme | Üç örnek fotoğraf ve albüm sayıları görüntülendi. |
| Ekleme | JPG dosyası seçilip “Galeri test fotoğrafı” kaydedildi, toplam dörde çıktı. |
| Fotoğraf güncelleme | Açıklama “Fotoğraf açıklaması güncellendi.” olarak değiştirildi. |
| Yorum ekleme | Test fotoğrafına “Fotoğraf yorum testi.” yorumu eklendi. |
| Yorum düzenleme | Yorum “Yorum güncellemesi başarılı.” olarak değiştirildi. |
| Kalıcılık | Sayfa yenilendi; fotoğraf, yeni açıklama ve düzenlenen yorum korundu. |
| Yorum silme | Yorum kaldırıldı; yorum sayısı sıfıra indi. |
| Fotoğraf silme | Onay sonrası test fotoğrafı kaldırıldı; galeri üç fotoğrafa döndü. |
| Albüm filtresi | Şehir seçildiğinde yalnız şehir fotoğrafı gösterildi. |
| Arama | “Sessiz” araması yalnız ilgili kartı gösterdi. |
| Responsive | 1440 px masaüstü ve 390 px mobil görünüm kontrol edildi. |
